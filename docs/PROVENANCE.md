# Sources and provenance

The integration source baseline is recorded in `SOURCE.json`. The public snapshot excludes historical deployment reports and runtime fixtures, and retains only the source helper required by the Windows adapter from the former outer application. The old Brain/application controller is not a production entry point in this publication.

Evidence-memory references: `D2767192219/dafeiyu`, commit `68638bacb49b236324859b353595c2168de2f18e`. The user reported permission to reuse the relevant code. `src/memory-core.mjs` implements evidence references, confirmed facts and separate daily recall/archive layers; `src/evidence-memory.mjs` adds WeChat scope and persistence. No source repository's private chats, credentials or memory database are copied. No QQ runtime or second model brain is introduced.

The referenced `third_party/dsh-qq-group` has its own SenuMirai MIT notices; that license does not cover unrelated source in the repository. The QQ implementation is not redistributed here.

The official provider balance capability retains its existing `vendor/official-provider-balance/LICENSE` and `PROVENANCE.json`. The runtime shim is generated only for an explicitly resolved, compatible local Harness installation. It does not distribute provider configuration or authentication values.

The independent owner tools retain `vendor/owner-tools/PROVENANCE.md`. Search reads public HTML using the standard HTTP stack, DOCX parsing uses ZIP/XML, and no paid search/fetch SDK or document execution engine is bundled.

External dependencies are installed separately: Python uiautomation, comtypes and Pillow; Node DeepSeek Harness and its native services. Respect their own licenses. WeChat, model weights and third-party applications are not redistributed.

Group participation and message mapping drew on published design ideas in AstrBot Group Chat Plus and pywechat/pyweixin. These references do not imply bundling those implementations or adopting their licenses for this repository.

Compatibility sources in `compat/` preserve the driver generation used with the source baseline. The public source manifest records its RPC hash. This is a component compatibility record, not a promise that every deployment or UI version behaves identically.
