# Independent owner task release

The application slice from a1054484 is deployed with independent native Agents for
owner reasoning and persona drafts. It returns a persistent task ID, supports
status/cancel and queues results for the original owner conversation. These are
runtime registrations and offline-SDK-verified paths. Real owner submission while
foreground chat continues, cancellation/result delivery, and deployed crash
reconciliation remain natural-use acceptance items. No paid calibration or task
probe was generated to claim completion.

The coordinated load passed actual provider budget attachment, sessionQuery,
owner tool schemas, group rejection, status/cache, balance/collector binding and
fresh driver polling. The measured guardian window was 20.13 seconds and the
observed poll gap was 19.96 seconds; this is not a future Windows startup guarantee.
The original session/identity/unknown-send ledgers and persona remain separate
from the new isolated task ledger. Legacy tasks are not migrated or replayed.

Future collector records can carry a host-receipt/native-turn/step/attempt origin.
Complete usage and valid natural-user origin are distinct prerequisites; family,
request coverage, price and consistency checks are still required. Wake, mixed,
missing or invalid origins never count as natural-user calibration. Earlier
unlinked records cannot be certified by time matching. Task-result notifications
are excluded from the host input receipt classification. Automatic rotation
remains OFF, regardless of record count.

The minimum task scope is reasoning and persona-edit. Generic installer,
diagnostic, attachment and file executor forwarding are not enabled by this slice.
